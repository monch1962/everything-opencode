PineScript Interactive Debugger

Advanced debugging tools for custom PineScript indicator development

Quick Start

Get started with interactive debugging in seconds:

# Start the debug server
/pine-debug server --port 3000

# Or use the direct command
node scripts/pinescript/debug-server.js
--file your-indicator.pine
Launch Debugger

Features

  • Real-time variable inspection
  • Breakpoint system with step-through
  • Live watch expressions
  • Interactive charts and visualization
  • Call stack tracing
  • Performance profiling

Variable Inspection

Inspect variables in real-time with historical tracking and value visualization.

Breakpoint Debugging

Set breakpoints, step through execution, and examine state at any point.

Live Charts

Visualize indicator outputs and intermediate calculations with interactive charts.

Performance Analysis

Profile execution time, memory usage, and identify performance bottlenecks.

Command Line Tools

Use the command line debugging tools alongside the web interface:

# Inspect variables
/pine-debug inspect --var "rsiValue" --bars 20

# Trace variable changes
/pine-debug trace --var "macdLine" --plot

# Profile performance
/pine-debug profile --metrics complexity

# Generate debug helpers
/pine-debug helpers --output debug-helpers.pine
